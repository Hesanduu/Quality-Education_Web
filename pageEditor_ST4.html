Compliance

  1. Acceptable Use

    The content on my site is appropriate for an academic setting, with no offensive or illegal material. No ads or commercial activities are present. If there were user-generated content, I’d moderate it to prevent misuse.

  2. Data Protection (GDPR)

    My site doesn’t collect unnecessary personal data. If any data is collected, users are informed via a privacy notice. Data is securely stored, and no personal data is shared without consent.

  3. Security

    I use HTTPS for secure data transmission, validate input to prevent cyber threats like SQL injections, and follow secure authentication practices.

  4. Accessibility

    I’ve followed the Web Content Accessibility Guidelines (WCAG 2.1) by providing alt text for images, ensuring keyboard navigability, and using high-contrast colors and readable fonts.

  5. Copyright

    All content on the site is either original or properly licensed, and third-party scripts are legally sourced and credited.

  6. Ethical Considerations

    The information on the site is accurate and properly credited. I’ve followed academic integrity standards to avoid plagiarism.

  7. Conclusion

    My web pages comply with Janet regulations, ensuring they are secure, ethical, accessible, and legal. Compliance is an ongoing process, and I will continue to improve security, accessibility, and standards.
